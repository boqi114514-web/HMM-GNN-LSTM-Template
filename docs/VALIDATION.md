# 母版验证记录

验证日期：2026-10-15。本记录针对独立母版的程序链路、架构和数据边界，不是新的真实行情收益报告。

## 验证环境

本地 Windows、Python 3.13.11；CPU 单线程运行。实际安装版本：NumPy 2.4.2、pandas 3.0.1、SciPy 1.17.1、scikit-learn 1.8.0、PyTorch 2.11.0+cu128、hmmlearn 0.3.3。虽然本地安装的 PyTorch 带 CUDA，演示在 CPU 上执行。

GitHub Actions 另配置 Ubuntu、Python 3.11、CPU PyTorch，自动执行单元测试和完整合成演示。远端是否通过以具体提交的 Actions 状态为准，不将本地通过写成远端通过。

## 单元与边界测试

执行 `python -B run.py test`，**29 项全部通过**。覆盖：

- 原始 HMM 参数、宏观特征、无未来数据影响、状态独热与动态融合。
- GAT / LSTM 网络尺寸、图只使用信号月之前的收益。
- 下一月标签与训练／验证截止边界，最新未实现月份保留。
- 缺失自然月或技术因子不能静默合并掉；验证／预测不能重拟合标准化器。
- 基本面与量价输入缺少末期行业节点时，在训练前拒绝。
- 延迟公布的收益标签不能提前参与 HMM 状态内权重学习。
- 按预测选股后再验证收益；不能因缺少未来标签换成其他行业。
- 首月亏损计入回撤、共同回测区间校验。
- 源码没有机器绝对盘符路径；导入模块不创建目录、不替换标准输出。
- 合成数据六个输入文件同种子可重复；已有目录不会被覆盖。

## 完整合成演示

执行 `python -B run.py demo --out results/smoke_20261015_verified`，退出码为 0。

| 项目 | 检查结果 |
|---|---|
| 输入 | 12 个虚构行业，78 个月，2010-01 至 2016-06 |
| HMM | 18 个可拟合月份，失败 0，非收敛标记 0 |
| GAT / LSTM | 各完成两个滚动训练窗口，各输出 72 行预测 |
| 信号月份 | 2016-01 至 2016-06，共 6 个月 |
| 已实现持有月份 | 2016-02 至 2016-06，共 5 个月 |
| 待实现月份 | 2016-06 的信号对应 2016-07，不补造收益 |
| 对照 | GNN、LSTM、固定 50/50、HMM 动态融合、行业等权共 5 组 |
| 数值检查 | 两分支预测及已实现月收益均为有限数值 |
| 审计检查 | 完成后重新计算全部源码和六个输入文件 SHA-256，与运行清单一致 |

演示保留完整架构与 60+12 月训练窗口，但神经网络仅训练 2 轮、1 个种子，HMM 最多迭代 20 次，用来验证能否从输入走到结果，不用于判断收益水平。默认 `train` 使用 `configs/base.json` 的参考训练参数。

短合成样本的 GLASSO 交叉验证过程中出现 NumPy 数值警告，最终图和预测通过有限值检查；代码保留拟合失败时退回相关图的原逻辑。时区时间转换为自然月时另有 pandas 提示，不影响月份校验。这些警告没有被全局屏蔽，也没有被当成收益结论。

## 本次发布边界

- 只发布源码、配置、测试、CI 与说明；合成运行输出亦留在本地、不进入 Git。
- 不打包原始行情、供应商数据、密钥、缓存或模型权重。
- 没有重跑真实市场参考配置；不声称复现旧版年化或后续基金实验收益。
- 基本面季度映射、宏观历史版本、行业成员历史、上游形态因子的时点有效性仍需数据层独立审核，详见 [数据契约](DATA_CONTRACT.md)。
- 母版保留行业指数收益评估，不包含个股交易资金账本。原有研究项目独立保留，不由本仓库替换。
